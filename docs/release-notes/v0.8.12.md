## 你专心写，它替你记得提交

盯着你指定的几个 Git 仓库，等你停手一段时间，问你要不要提交；你点确认，它就按你看到的文件清单提交。

改了一下午，关机前才想起来没提交；或者连着提交三次，第四次忘了，第二天一个 `git checkout .` 抹掉一整天——这类事故不是不会用 Git，纯粹是没人提醒。这个工具就是那个提醒。

### 三个模式

| 模式 | 停手后 |
| --- | --- |
| 弹窗提醒（默认） | 弹卡片列出会提交的文件，你确认才提交 |
| 自动提交并通知 | 直接提交，发一条 Windows 通知 |
| 完全静默提交 | 直接提交，只记日志 |

### 它凭什么不乱提交

只提交**你看到的那份清单**（临时索引精确锁路径，不是整仓 `add -A`）；版本变了、有未收尾的事务、游离 HEAD、正在 merge/rebase、没配 git 身份、装了 pre-commit 钩子且失败——都会如实阻断而不是硬提交。单次改动超过 500 个文件自动降级成弹窗。

不改写历史、不 push、不切分支、不跳过钩子。

### 需要先装

- **Git for Windows**（必需）
- **PowerShell 7**（「弹窗提醒」模式需要；程序会自查，缺了会挡住界面并给下载按钮）
- Git 提交身份（`user.name` / `user.email`）

### 安装

下载下面的 `GitQuietHelper-0.8.12-setup.exe`，双击，等进度条走完。装到 `%LOCALAPPDATA%\Programs\GitQuietHelper`，不需要管理员权限。

### 说明

- 只有 Windows；只做本地提交，不推送远程
- 所有逻辑在本地跑，不登录、不上传、不统计
- 单纯想看看代码或自己构建：仓库里 `npm install && npm run app`
