## 0.8.20

0.8.19 的内容也包含在本版里（0.8.14–0.8.19 从未发布过），所以这里一并说明。

### 1. 「活动」页：先说清「现在为什么没提醒」

原来的「日志」页只有自动提交记录和原始输出——remind 模式下点确认的提交根本不记录，也看不出工具到底在等什么。现在：

- 每个项目一行主原因：运行标记未结束（带 token 与已持续时长，可一键收尾）／上次提交没收尾／需人工核对／稍后提醒中（到几点）／本次不提交／冷却中／未配身份／分支不符／等停手／可以提醒／干净。
- 最近活动：确认提交、弹窗提醒、跳过、稍后提醒、直接关窗、确认失效、收尾清理、运行标记开始/结束、监视启停、自动提交上限与失败。
- 原始监视输出折叠到页尾，需要排查时再展开。

外部自动化用 `guard begin` / `guard end` 占住仓库，如果它 begin 完忘了 end，这个仓库就永远不提醒——而且原先一行日志都不会写。现在这条原因直接显示在活动页，点「收尾」即可结束。

### 2. 本次修掉的问题

- **已跟踪的 `dist`/`build`/`vendor` 改动会被静默忽略**：忽略目录对已跟踪文件也生效，导致这些改动既不提醒、也永远提交不了。现在忽略规则只作用于未跟踪文件。
- **点「保存」会把开机自启关掉**：界面提交配置时不带 `autoStart`，服务端用默认值 false 补齐，下次启动就按 false 摘掉自启项。现在界面带上该字段，服务端在字段缺失时保留原值。
- **卸载依赖 PowerShell 7、且不清开机自启**：只有 5.1 的机器装得上却卸不掉（`卸载.cmd` 与「应用和功能」里的卸载命令都写死 `pwsh`）；卸载后还残留一条指向已删除程序的自启项。现在会回退到系统自带的 `powershell.exe`，并删除自启项。
- **状态目录只增不减**：成功提交后 `attempt-*` 一直留着，「确认失效」记录越积越多。现在提交成功后立即删除，启动时再清掉 30 天前的诊断/冷却记录。
- **提交被打断留下的 `.git/index.lock` 只能干等**：现在活动页会指出真实锁路径（worktree 下也正确），确认没有别的 git 操作后可一键清理（有二次确认）。
- **`git rm --cached` 之后同一路径既被删除又是未跟踪**：过去报「提交范围为空、重复」并且永远提交失败；现在合并成一条原因，说清需要人工决定「恢复跟踪」还是「提交删除」，不再尝试空提交（空提交失败会留下永久门禁）。

### 3. 升级说明

- 覆盖安装即可；配置与状态保留在 `%APPDATA%\git-quiet-helper`。
- 安装完会自动启动一次，之后开机自启（如果开着）。
