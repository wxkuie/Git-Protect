Git 静默提交助手

这是什么
  你在项目里停手一段时间后，它把这个项目还没提交的改动提交到本地 Git 仓库。
  不联网、不推送、不切分支。

怎么装
  1. 解压这个压缩包到任意位置（不用管理员权限）。
  2. 双击 安装.cmd。
  3. 装完会自动打开窗口。之后从开始菜单「Git 静默提交助手」启动。

装到哪里
  程序：%LOCALAPPDATA%\Programs\GitQuietHelper
  配置与提交记录：%APPDATA%\git-quiet-helper

需要什么
  - Git for Windows（提交靠它）
  - PowerShell 7（弹窗确认那一步需要）

三点要知道的事
  1. 关掉窗口不等于退出：它会收进托盘继续监视。要真退出请用托盘右键菜单。
  2. 自动提交直接改你的仓库历史，提交前不问你。不确定的项目请用「弹窗提醒」模式。
  3. 第一次装完还没有项目。点「添加项目」→「选择文件夹…」把项目加进来。

怎么卸载
  双击 卸载.cmd，或在「设置 → 应用 → 已安装的应用」里找到「Git 静默提交助手」卸载。
  卸载时会问要不要一并删除配置和提交记录。
